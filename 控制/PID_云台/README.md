# 《手推到狗跑》PID：积分消偏差，微分给阻尼

配套 B 站视频：《手推到狗跑》P 给大点，为什么反而失控了？（链接见视频简介）

## 怎么用

1. **先手推**：打印 `练习单.pdf`，在纸上推完五道题。
2. **再对答案**：`练习单_答案.pdf`。
3. **最后用代码验证**：打开 `PID云台_验证.ipynb`，把你推出的公式填进“填你的公式”格子，和仿真结果对照；再改改参数，看看会发生什么。

## 运行环境

Python 3.9+，安装依赖：

```
pip install -r requirements.txt
jupyter notebook PID云台_验证.ipynb
```

不想装环境：直接在网页上看 notebook（图已经跑好）。
