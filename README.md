# 手推到狗跑

B 站系列《手推到狗跑》的配套练习：从一个电机、一根云台，一路手推到让四足机器狗跑起来。

每一期都是同样的用法：

1. **先手推**：打印 `练习单.pdf`，在纸上推。
2. **再对答案**：`练习单_答案.pdf`。
3. **用代码验证**：打开 `.ipynb`，把你推出的公式填进去，和仿真对照，再改参数玩一玩。

适合：想入门机器人控制的新生、RoboMaster / Robocon 队员。只需要一点高数和线代。

## 运行环境

Python 3.9 以上。进入某一期的文件夹后：

```
pip install -r requirements.txt
jupyter notebook
```

四足的几期要用 MuJoCo 物理仿真（`requirements.txt` 里已包含，`pip install mujoco` 即可，不需要显卡）。

不想装环境也没关系：notebook 里的图都已经跑好，在网页上直接就能看。
