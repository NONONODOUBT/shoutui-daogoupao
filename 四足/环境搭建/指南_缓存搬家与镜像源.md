# 指南：缓存搬家、镜像源、什么时候需要 Ubuntu

配套《手推到狗跑》环境搭建期。标了“作者实测”的步骤在作者的 Windows 11 笔记本上跑过；其余是各工具官方文档的写法，以官方文档为准。

## 1. 缓存搬家（作者实测）

每一个都是三步：**查它在哪 → 搬过去 → 再查一遍**。把 `D:\...` 换成你电脑上**真的存在**的盘。

### pip

```
pip cache dir
python -m pip config set global.cache-dir D:\cache\pip
pip cache dir
```

再装一个包，新目录里会出现 `http-v2` 文件夹。

> **坑（作者实测）**：写成一个不存在的盘之后，每一条 pip 命令都会崩溃（`OSError: [WinError 1005]`），连 `pip config list` 都跑不了。救法：打开 `%APPDATA%\pip\pip.ini`，删掉或改对 `cache-dir` 那一行。

### conda

```
conda config --show pkgs_dirs envs_dirs
conda config --add pkgs_dirs D:\conda\pkgs
conda config --add envs_dirs D:\conda\envs
conda config --show pkgs_dirs envs_dirs
```

要用 `--add`（插到列表最前面），不是 `--append`（放到最后，不起作用）。改完以后新下载的包、新建的环境才会放过去；已有的环境不会自动搬。

### 模型缓存（以后 RL 期会用到）

```
echo %HF_HOME%
setx HF_HOME D:\cache\huggingface
setx TORCH_HOME D:\cache\torch
```

`setx` 写的是用户环境变量，**新开一个终端**才生效，再 `echo %HF_HOME%` 确认。Linux / macOS 在 `~/.bashrc` 里写 `export HF_HOME=...`。

## 2. 国内镜像源

下载慢可以换镜像。下面是清华 TUNA 镜像站帮助页的写法，镜像地址偶尔会调整，以镜像站帮助页为准：

- pip：`python -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`
- conda：按 [TUNA 的 Anaconda 镜像帮助](https://mirrors.tuna.tsinghua.edu.cn/help/anaconda/) 改 `.condarc`。中科大镜像见 [USTC 镜像帮助](https://mirrors.ustc.edu.cn/help/)。

## 3. 什么时候需要 Ubuntu

- **这门课前面的部分（MuJoCo CPU 仿真、notebook）**：Windows 就够了，前三期都是在 Windows 上做的。
- **后面用显卡并行训练（Isaac Lab、MuJoCo Playground、mjlab 等）**：各框架的官方文档主要按 Linux 写，部分明确推荐 Ubuntu 22.04、对 Windows / WSL 只做过初步测试。到那一步建议装原生 Ubuntu（双系统），而不是 WSL。这部分作者还没有在本机安装验证，到对应那期会实测后再更新。

装 Ubuntu 的大致步骤（以 Ubuntu 官方安装文档为准）：

1. 从 ubuntu.com 下载 Ubuntu 22.04 LTS 桌面版镜像，用 Rufus 之类的工具写进 U 盘；
2. 在 Windows 里先压缩出一块空闲分区（建议 ≥ 200 GB，训练环境和数据都很占地方），并备份重要文件；
3. 从 U 盘启动，安装时选“与 Windows 共存”或手动分到那块空闲分区；
4. 装好后先装显卡驱动（`sudo ubuntu-drivers autoinstall`，重启后 `nvidia-smi` 能看到显卡）；
5. 装 Miniforge，用同一个 `environment.yml` 建课程环境，再跑一遍体检。
